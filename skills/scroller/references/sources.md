# Daily source policy

Use live primary sources where possible and record the exact retrieval timestamp. Source availability and APIs change; verify the current access method during every run.

## TikTok

Prefer TikTok's own Creative Center, public trend or chart surfaces, or user-provided exports. Record country, time window, rank, creator, post URL, and visible metric. If direct chart data is unavailable, use attributable third-party discovery only as a candidate signal and label the final ordering editorial_rank. Never claim a global TikTok rank from a local or personalized feed.

## GitHub

Prefer GitHub Trending and GitHub's API or repository pages. Record language or filter, time window, stars or stars gained when available, repository URL, license, and last activity. Distinguish all-time stars from daily momentum.

## Podcasts

Prefer publisher charts such as Apple Podcasts or Spotify and corroborate episode metadata with the show's RSS feed or publisher page. Record country, category, chart type, show or episode title, publisher, publication date, and canonical link. Do not present rating counts as listening totals.

## Wikipedia

Prefer Wikimedia Pageviews or official Topviews data. Record project and language, access type, date, pageviews, rank, article URL, and whether automated or bot traffic exclusions apply. Pageview data may lag; state the actual chart date.

## AI context

Build an editorial ranking from primary announcements, official documentation, research papers, model or system cards, reputable benchmarks, and high-quality reporting. Divide candidates across personal use, business, development, creative work, safety or policy, and notable models or tools. Record publication date, primary URL, corroborating URL when needed, audience, and the concrete reason it matters today.

## Evidence minimum

Every candidate needs:

- source, title, and canonical URL
- retrieved_at in ISO 8601
- ranking_type as published_chart or editorial_rank
- metric or a concise evidence statement
- a factual summary
- rights-safe image_url or a generated-visual prompt plan

Exclude candidates whose core claim cannot be verified.
